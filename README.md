# Mind List

Aplicação web de gerenciamento de projetos e tarefas desenvolvida com foco em organização, produtividade e experiência do usuário.

O projeto permite criar projetos personalizados, organizar listas e tarefas, acompanhar status de progresso e gerenciar tudo em tempo real através do Supabase.

## 🚀 Sobre o Projeto

O Mind List foi desenvolvido como um sistema completo de produtividade inspirado em ferramentas modernas de organização.

Cada usuário possui sua própria conta e pode:

• Criar projetos <br/>
• Alterar status dos projetos <br/>
• Criar listas dentro dos projetos <br/>
• Adicionar tarefas em cada lista <br/>
• Editar informações em tempo real <br/>
• Excluir projetos, listas e tarefas <br/>
• Organizar tudo de forma visual e intuitiva <br/>

A aplicação possui autenticação funcional, persistência de dados e comunicação direta com banco de dados em tempo real.

## ⚙️ Como Rodar o Projeto

Clone o repositório: <br />
```git clone https://github.com/seuusuario/mind-list.git```

Entre na pasta: <br />
```cd mind-list```

Instale as dependências: <br/>
```npm install```

Execute o projeto: <br /> 
```npm run dev```

## 🔑 Variáveis de Ambiente

Crie um arquivo .env: <br/>
```VITE_SUPABASE_URL=sua_url``` <br/>
```VITE_SUPABASE_ANON_KEY=sua_chave```
